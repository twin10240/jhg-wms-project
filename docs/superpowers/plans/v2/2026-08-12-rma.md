## 핵심 설계 결정

1. **Reservation FOR UPDATE**: RMA 접수 직렬화의 유일한 잠금 지점. 모든 RMA 생성 경로가 이 잠금을 먼저 획득해야 함
2. **applyDelta 재사용**: RESTOCKED 재고 반영에 기존 경로 사용 → OMS 백오더 승격 통지 자동 발생
3. **OmsReturnStatusNotifier**: OmsReplenishmentNotifier 패턴 복제 — afterCommit + best-effort
4. **RmaResponse 공용**: GET 응답과 OMS 콜백 본문에 동일 DTO 사용
5. **requestKey 멱등**: DB UNIQUE + 내용 비교로 201/200/409 분기
