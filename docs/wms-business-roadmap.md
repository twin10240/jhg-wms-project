## 현재 완료

| 영역 | 구현 상태 |
|---|---|

| 예약 | `orderId` 멱등 원장(품목·수량 불일치 시 `409`), `RESERVED / SHIPPED / RELEASED` |
| 재고 원장 | `OPENING / RECEIVE / SHIP / ADJUST / RETURN / COUNT`, 참조와 전후 수량 |

| 발주 | 다품목 생성, 품목별 누적·잔여수량, 부분입고·전량입고·취소 |

| 반품(RMA) | 접수(멱등), 입고, 검수(부분승인·처분), 재입고(`RETURN` 원장), OMS 콜백 |
| 재고 실사 | 세션 기반 계수·승인 분리, 승인 시점 차이 재계산, `COUNT` 원장, 원장 행위자,

| 회복탄력성 | 타임아웃, best-effort OMS 통지, OMS 보상 스윕 |

| 반품 사유 분류 | 접수 커밋 후 별도 스레드에서 Claude 호출, 구조화 출력, 참고 표시 전용 —
  재고·상태·검수 폼에 영향 없음. 키 미설정 시 분류만 비활성 (V4.0) |

### 3. 안전재고·재주문점

상품별 안전재고와 재주문점을 두고 기준 이하일 때 보충 제안을 만든다.
현재 OMS 주도 보충 요청으로 포트폴리오 서사가 충분하므로 자동발주는 보류한다.

### 4. 위치·다중창고

재고를 `(product, location)` 단위로 분해하고 적치·피킹을 모델링한다.
현재 데이터 모델을 크게 바꾸므로 진짜 창고 위치 서사가 필요할 때만 착수한다.
V3.0에서 실사의 계수-승인 사이 물리 이동 문제는 위치 단위 동결이 필요함이 확인됐다. 이 항목이 그 전제다.

### 5. 메시지 기반 통신

OMS 콜백을 durable outbox 또는 메시지 브로커로 전환한다.
현재 best-effort 콜백과 OMS 보상 스윕의 지연이 실제 문제가 될 때 도입한다.
