# WMS 관리자 UI/UX 현황과 후속 작업

최종 현행화: 2026-07-26

## 완료

- 공통 `admin.css`와 레이아웃, 폼 로그인 화면
- 현재 사용자·역할 표시와 로그아웃
- `OPERATOR / MANAGER` 역할별 메뉴·액션 노출
- 보충 요청·발주·예약 상태 한글 표시
- 보충 요청 승인·반려 메시지 한글화
- 발주 목록의 누적 입고량·발주량·진행률
- 발주 상세의 잔여수량 기준 부분입고
- `ORDERED / PARTIALLY_RECEIVED` 발주 취소와 연결 요청 종결
- 별도 재고 트랜잭션 이력 화면과 유형 필터
- 상품명, `주문 #N`·`발주 #N` 참조 표시
- 대시보드의 검토 대기 요청·부분입고 발주·가용 0 SKU 집계
- 넓은 표의 컨테이너 스크롤과 flash `role="alert"`

## 포트폴리오 1차 검증 대기

- 375px와 1280px에서 핵심 작업이 가려지지 않는지 확인
- 실제 데이터로 대시보드 집계와 목록 건수 대조
- OPERATOR 버튼 미노출과 직접 POST `403` 확인
- 로그인 성공·실패·로그아웃, API 미인증 `401` 확인

## 1차 이후 후보

### 재고 조정 안전성

- 상품 선택 시 현재 보유·예약·가용수량 동시 표시
- delta 입력 중 조정 후 예상 보유수량 표시
- 음수 조정 사유 필수와 별도 확인
- 완료 flash에서 변경 전후 수량과 원장 링크 제공

현재 서버는 0 미만과 예약수량 미만 감소를 방어하고 모든 성공 조정을 원장에 기록한다.
예측 UI는 수동 검증에서 오입력 위험이 확인될 때 추가한다.

### 목록 탐색

- 재고 기본 정렬을 가용수량 오름차순으로 변경
- 대시보드 숫자를 정확한 상태 필터 목록으로 연결
- 원장 상품·기간 검색 또는 페이지네이션

현재 데이터는 20 SKU이고 원장은 최신 200건으로 제한돼 있어 1차 범위에서는 보류한다.

### 모바일 밀도

- 넓은 표를 카드형 행 또는 핵심 열 우선 표시로 전환
- 버튼·입력의 터치 영역 추가 조정

현재는 표 컨테이너 내부 스크롤을 사용한다. 수동 검증에서 핵심 작업이 어려울 때만 확장한다.

## 제외

- 위치·빈, 자동 재주문
- 새 프런트엔드 프레임워크
- 실시간 WebSocket 대시보드

신규 도메인 기능은 [`wms-business-roadmap.md`](wms-business-roadmap.md)에서 관리한다.
